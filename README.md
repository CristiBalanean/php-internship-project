# 💰 Family Budget Tracker

A full-stack web application for managing household finances, built during my internship at **Evozon** (Cluj-Napoca, Romania).

---

## About

The Family Budget Tracker lets users track income and expenses, categorize spending, and view monthly budget summaries. Built as a two-person team project — I developed this 50/50 with my teammate, who hosted the original repo at [petreasil/team_project](https://github.com/petreasil/team_project). We worked in an Agile environment with sprint ceremonies, code reviews, and delivered a final technical demo to stakeholders.

---

## Features

- User authentication and registration
- Add, edit, and delete income and expense entries
- Expense categorization (food, bills, transport, etc.)
- Monthly budget summaries and overview
- Responsive front-end interface

---

## Tech Stack

- **Back-End:** PHP, Symfony (MVC architecture)
- **Templating:** Twig
- **Database:** MySQL with normalized schema design
- **Front-End:** JavaScript, HTML, CSS
- **Testing:** PHPUnit
- **Infrastructure:** Docker, Shell scripts
- **Version Control:** Git with peer code reviews
